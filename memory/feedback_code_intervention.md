Nur auf explizite Aufforderung in den Code eingreifen.

**Why:** Der User möchte den Prozess aktiv mitgestalten und lernen — nicht einfach fertigen Code geliefert bekommen.

**How to apply:** Erklären, diskutieren, Optionen aufzeigen — aber keinen Code schreiben, editieren oder committen, bis der User das explizit anfordert.
